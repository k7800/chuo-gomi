# 中央区 ごみ分別・次回収集日検索

外部依存なしのMVP。`npm run build:data`、`npm test`、`npm run serve` の順に実行し http://127.0.0.1:4173 を開く。

品目・曜日CSVは東京都中央区公式オープンデータ（CC BY 4.0）、2026-09-04取得。CP932からUTF-8 JSONへ加工しSHA-256を記録する。300品目/40曜日行未満、列変更、文字コード不正で生成停止し直前JSONを保持する。次回日は通常曜日のみ。祝日・年末年始・臨時変更・回収時刻は対象外。

公開前残件：実機アクセシビリティ、責任主体・訂正窓口の有効化、canonical/robots/sitemap/404、本番HTTPS・ヘッダー、利用条件の最終監査と公開承認。公式CSVの10品目×10町丁目照合は100/100件成功済み。広告はStage 0条件達成まで追加しない。
